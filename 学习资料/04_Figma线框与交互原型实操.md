# Figma 线框与交互原型实操

整理日期：2026-11-10。对应问题：“如果是我来做应该要怎么做。”本篇是练习建议，本轮没有创建 Figma 文件或重做正式线框。

## 练习目标

先完成一页 NED 详情的桌面与手机低保真线框，能够解释内容顺序、演示查看成果与返回入口。以内容和操作为验收重点，先使用灰框与系统字体。

## 先认识几个工具名

| 名称 | 含义与用途 |
| --- | --- |
| Frame | 画框，承载一个页面或界面状态，可以嵌套 |
| Auto Layout | 自动布局，按规则组织元素、间距与尺寸行为 |
| Component | 可复用组件，适合导航、按钮和卡片等重复内容 |
| Prototype | 连接界面与操作的原型功能 |
| Navigate to | 跳转到另一个画框，模拟页面导航 |
| Open overlay | 打开浮层，可模拟菜单或大图查看 |
| Close overlay | 关闭当前浮层 |
| Scroll to | 在相同滚动界面中定位到指定内容 |

具体菜单位置可能随软件版本变化，练习时按当前界面操作。

## 第一步：先写内容，再画框

把 NED 的内容列成表，每段写清楚“希望读者知道什么”：

| 章节 | 内容职责 |
| --- | --- |
| 概述 | 名称、模拟性质、项目目标与范围 |
| 我的工作与 AI 协作 | Migo 的实际贡献与工具执行范围 |
| 设计判断 | 选择当前方向的依据 |
| 四段完整成果 | 商品图／Listing、高级 A+、品牌故事、Banner |
| 简短复盘 | 真实迭代、限制和改进 |
| 后续入口 | 返回作品、了解 Migo、联系 |

内容以[案例资料卡](../文档/首篇案例资料卡.md)为准，不把模拟项目写成真实品牌委托。

## 第二步：建立两个页面画框

创建桌面 1440px 与手机 390px 宽的画框，名称例如“NED详情_桌面_练习”和“NED详情_手机_练习”。这两个宽度沿用本轮结构检查示例；页面高度随内容延伸。

先放顶部导航、正文和页脚。正文按章节从上到下排列，图片用矩形占位，标注内容及版本。为长页面原型设置适当的视口与纵向滚动；内容总高度与屏幕视口高度是两个概念。

## 第三步：用 Auto Layout 组织内容

为正文建立纵向布局，章节内部再按需要安排分栏或单列。给内容设置合理的固定宽度、填充容器或适应内容行为，观察文字增长后的变化。

优先保持同类标题、段落和按钮的规则一致。间距用于区分章节、组与单项，先保证关联内容靠近、阅读顺序明确。具体数值作为练习起点，依实际字数和画面调整。

## 第四步：单独思考手机结构

手机稿需要检查菜单、章节目录、换行、按钮和图片查看方式。桌面多列通常需要改为单列，但不能只把整个桌面稿等比缩小。

NED 的 A+ 要保留完整状态清单。灰框可以代表具体素材，但不要为了缩短画布随意删掉手机状态。是否采用分段、缩略列表或放大层，要说明完整内容如何可达。

## 第五步：连接原型

| 操作 | 练习中的连接方式 | 检查重点 |
| --- | --- | --- |
| 点击“查看项目” | Navigate to → NED 详情画框 | 是否进入对应案例 |
| 点击“返回作品” | Navigate to → 作品列表画框 | 是否有明确返回路径 |
| 点击章节目录 | Scroll to → 相应章节 | 是否定位到正确内容 |
| 展开手机菜单 | Overlay 或适合的组件状态 | 入口、关闭和后续点击是否清楚 |
| 点击图片查看细节 | Open overlay → 大图画框 | 是否能看清当前项并关闭 |
| 关闭大图 | Close overlay | 是否回到原阅读位置 |
| 点击语言入口 | 跳到同一案例的另一语言练习画框 | 案例身份保持一致，未完成译文明确标记 |

先做最小路径，不必同时模拟所有功能。只有当读者理解需要或交互差异值得验证时，再增加相应状态画框。Figma 自动布局也不会自动替你完成整套响应式设计。

## 第六步：完成一次任务测试

打开演示模式，请另一人完成以下任务，先观察，再解释：

1. 找到 NED 属于什么性质的项目。
2. 说明 Migo 做了什么，AI 做了什么。
3. 找到高级 A+ 的完整手机内容，打开一个图位后返回。
4. 从案例进入关于或联系，再回到作品列表。

记录对方停顿、误点、找不到的信息和理解偏差，再修改线框。按钮能点通只是其中一部分，还需要理解内容。

## 怎样算完成这次练习

- [ ] 能解释每个主要章节的职责。
- [ ] 桌面和手机都能找到案例性质、个人贡献和成果。
- [ ] 查看、关闭、返回与导航行为清楚。
- [ ] 完整素材范围有清单，不以占位隐藏内容缺失。
- [ ] 缺少的联系方式、译文和品牌资产都有明确状态。
- [ ] 保存反馈与修改理由，能够说明为何调整。

这一练习重点涉及信息架构、交互设计与原型表达。练习稿不自动成为本项目的新交付版本；如要替换第一版线框，应另行记录采用范围和用户反馈。
