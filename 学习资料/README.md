## 与项目文件怎样配合

- 学习资料用于理解方法，实际需求以[网站项目简报](../网站项目简报.md)为准。
- 页面范围看[网站地图](../网站地图.md)，执行任务看[下一阶段任务表](../文档/下一阶段任务表.md)。
- NED 的事实、个人分工和素材版本看[案例资料卡](../文档/首篇案例资料卡.md)，不把教学示例当作已确认的项目事实。
- 实际成品看[第一版线框](../线框/第一版/README.md)，操作与内部检查范围以交付记录为准。
- 项目决定和用户确认看[决策日志](../网站决策日志.md)。学习笔记不另建一套品牌定义或验收结论。

当前项目示例基于已交付的第一版线框：六类页面、桌面／手机共 12 份基础视图，待用户审阅。后续学习资料可以随新问题继续补充；1440／390 的示例尺寸、NED 的章节结构与具体工具选择均不作为所有网站的统一标准。
