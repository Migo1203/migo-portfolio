## 推荐执行顺序

1. 先完成 T01–T02 的内容确认，再执行 T03。NED 最复杂、现有资料也最充分，先验证案例详情，可让首页与列表引用真实字段。
2. 详情结构稳定后，完成 T04–T05，连接六类页面。
3. 完成 T06–T07，检查中英文长度、手机阅读及返回路径，逐项验收；线框完成不自动等于 UI 已获准。
4. T08 只更新状态与后续输入。品牌色、字体、Logo 与 Beedog 正式资产按实际确认状态逐项接入。

这套结构应能支持未来品牌 IP 案例：共用概述、职责、设计判断、成果与复盘字段，成果段按项目类型变化。未来品牌案例可展示实际完成的策略、Logo、角色和规范，不强套 NED 的 Listing／A+ 章节。
