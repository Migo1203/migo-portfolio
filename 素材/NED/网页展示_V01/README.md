# NED网页展示 V01｜派生素材

日期：2026-11-15。用于[网页展示样稿V01](../../../UI设计/NED网页展示/V01/README.md)。原件留在AIGC，固定读取提交`4929b4063e74fd11642b6ff83c32f9f1f31deba1`，不覆盖原图、不新增生图。

本目录包含无文字客厅、餐桌暮色、产品抠图和八张商品图，共11个WebP副本。使用设计资源库已核验的`图片交付.py`，长边上限1600、质量90；不放大，保留透明度，RGB ICC转sRGB。场景取景由网页CSS处理，成果图不裁切。

Inter和Noto Sans SC为在库OFL字体，按样稿实际文字导出WOFF子集、保留可变字重；当前环境无Brotli编码器，因此使用受支持的WOFF格式。分别保留`Inter_OFL.txt`与`Noto_Sans_SC_OFL.txt`。它们是UI候选，不是Migo已确认品牌字体。

[统一交付清单](交付清单.json)记录原路径、原件与输出SHA256、尺寸、字体来源、处理及字节数。字体取自设计资源库的真实文件，不能从本批归档推定其他字体或项目已经授权采用。未来正式网站可重新评估WOFF2、缓存、字形范围及响应式规格，不直接以此样稿包作为生产性能方案。
