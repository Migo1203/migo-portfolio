# Dennis 网站交互与动效拆解

日期：2026-11-11。本文归档同一对话中已经完成的交互观察和源码核对，补充[此前的结构与静态拆解](丹尼斯个人网站拆解.md)。本次上传没有重新执行网站操作；不把研究建议写成 Migo 已采用或已实现。

## 1．研究来源与证据边界

原始入口：[首页](https://www.dennissnellenberg.com/) · [作品页](https://www.dennissnellenberg.com/work) · [The Damai](https://www.dennissnellenberg.com/work/the-damai)。

实现依据：[公开交互脚本](https://www.dennissnellenberg.com/assets/js/index-new.js) · [公开样式](https://www.dennissnellenberg.com/assets/css/style-new.css)。源码只保留原链接；没有将第三方完整代码或作品图片提取为 Migo 的网站资产。

证据见[交互观察记录](../研究记录/丹尼斯交互观察记录.json)：包含实际动作后的状态、桌面导航位移、手机菜单状态、作品预览位置、原始采集异常，以及 12 张观察截图的尺寸与 SHA-256。

观察分为三类：**实际触发并查看画面**、**源码可确认的实现**、**尚未验证**。前者不自动证明全站效果、真实设备性能或无障碍质量。

## 3．磁吸按钮如何成立

**观察：** 本次鼠标位置下，Work 链接的位移约为横向 5.43px、纵向 3.30px；内层文字约为 2.71px、1.65px；离开后恢复为 0。这是单次位置读数，不是固定参数或推荐值。

**源码依据：** 鼠标相对元素中心的位置决定目标偏移；按钮和文字有不同强度，动画逐渐接近目标，离开时复位。脚本中的磁吸位移初始化带有窗口宽度条件。

**分析：** 不同层的轻微位移增加层次和触感；如果移动过大，用户需要追逐入口，反而影响操作。

**对 Migo 的建议：** 先用明确的颜色、边框、下划线和焦点反馈。磁吸列为后续候选，不作为主导航必需效果；手机与减少动态效果时保留静态入口。对应[M01／M07 清单](../交互与动效清单.md)。

## 4．作品跟随预览如何成立

完整行为链为：进入项目行 → 识别当前项目 → 显示预览 → 移动鼠标时跟随 → 切换到另一行时换图 → 离开列表收起 → 点击进入详情。

**实际观察：** 同一作品内移动时，预览位置变化；切换 TWICE 与 The Damai 时图像内容变化；离开后 active 状态移除。预览中有 View 提示，列表行仍承担项目入口。

**源码依据：** 指针位置与图像／文字提示的位置逐步靠近，而不是瞬时相等；悬停项目索引驱动图像容器的纵向切换；进入和离开时控制显示状态。

**分析：** 文字列表由此获得图像预览，但浮动图片会覆盖部分文字，且依赖精确指针。它是呈现方式，不是作品浏览的必要条件。

**对 Migo 的建议：** 首版直接显示缩略图、项目名称与类型，触摸直接进入。后续若探索跟随预览，不能把它当作唯一图像入口，也不能遮挡关键操作。对应 I02、M04、M07。

## 5．手机菜单与页面过渡

### 菜单

**实际观察：** 手机菜单从屏外状态进入整屏；背景为深色，Home、Work、About、Contact 纵向排列，社交入口在下方，右上角为明显关闭按钮。关闭后回到首页。

**源码依据：** 点击切换菜单与主区域的状态类；CSS 控制面板 transform 过渡；脚本还包含 Escape、点击背景关闭及停止／恢复滚动的处理。后几项只核对了源码，未全部在本次操作中验证。

**对 Migo 的建议：** 首版优先保留第二版的行内手机菜单；如果将来选整屏菜单，须一起定义焦点、关闭方式、背景可操作性与滚动恢复，而不只制作滑入画面。对应 I03、M02。

### 页面切换

**实际观察：** 点击 The Damai 后，深色曲面遮罩进入，再展示项目详情；目标 URL 已变化。进入后截图能看到项目标题、职责、署名与作品开篇。

**源码依据：** 页面切换协调离开、进入与相关滚动初始化；遮罩通过动画序列控制。

**对 Migo 的建议：** 先保证普通链接、返回、语言和章节定位正常。整页过渡列为后续探索，不增加人为等待；减少动态效果时直接切页。对应 I01、I02、M06。

## 6．实现线索与未验证内容

| 实现线索 | 本次能说明什么 | 不能据此推定什么 |

| GSAP | 公开脚本使用它控制位移、缓动与动画序列 | Migo 必须引入同一依赖，或本次已测得所有动画时长 |
| ScrollTrigger | 用于滚动状态和动画关联 | 整站滚动手感、所有视差和各设备效果已验证 |

首页姓名循环与滚动方向联动在源码中有依据；本次截图可以看到不同时刻的姓名位置，但未完整验证滚动方向、全部进入动效或连续节奏。不能把它们全部列为已实测通过。

## 7．采集限制与更正

- 最初网页交互工具没有可靠完成悬停、菜单和详情操作，其基于 class 名称的推测未作为本报告的验证依据。“没有加载遮罩”的初步判断被后续捕捉到的遮罩状态纠正。
- 云端原生 HTTPS 导航遇到环境证书信任错误，随后使用继承环境 CA 校验的真实 HTTPS 响应渲染，再执行鼠标、滚轮和点击；没有关闭 TLS 验证。分析跟踪、非 GET 和媒体请求被屏蔽，因此不测量原生网络速度。
- 初次首页作品悬停因自动滚入视口与平滑滚动的配合出现超时；后续在作品页补查。不能把该超时直接认定为网站缺陷，也不能宣称首页作品动效已完整验证。
- 详情进入截图保存后，采集辅助函数尝试读取该页不存在的元素，导致状态提取异常。原始异常已保留；它不是被观察站点的脚本错误，不能将本次采集描述为全程无异常。
- 未完成桌面菜单、全部滚动联动、真实手机、性能、读屏、键盘以及减少动态效果的完整测试。未测量精确耗时、帧率或动画对转化的影响。

## 8．对 Migo 的采用建议

**优先：** 稳定的导航、作品入口、手机菜单、图组查看与返回，再比较轻量状态过渡。

**后续：** 磁吸、跟随预览、曲面整页过渡、姓名跑马与复杂滚动。Dennis 同时展示设计与开发能力，Migo 当前优先展示视觉作品与真实贡献，采用范围需要不同。

具体候选、手机与减少动态效果方案、参数和验收任务集中在[Migo 交互与动效清单](../交互与动效清单.md)，不在此重复建立另一套规则。所有采用意见仍待用户审阅；本轮上传研究不修改在线审阅稿。
