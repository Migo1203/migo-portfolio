# UI 设计简报

更新日期：2026-11-10。阶段：UI 准备与视觉研究。本简报为后续视觉样稿提供输入，不是最终品牌或界面规范。

## 目标与验收对象

网站优先服务求职，兼顾后续商业合作。最新品牌资料已记录深圳 AIGC／视觉设计岗位方向；具体职位要求及访客反馈尚未研究，不能把设计假设写成招聘方已验证偏好。

界面应帮助访客理解 Migo 的方向、找到项目、区分个人贡献与 AI 执行、查看成果并找到关于／联系入口。作品是主体，品牌与 Beedog 支持记忆，不占用案例主要阅读空间。

用户已经审阅现有线框并要求继续，本轮按当前结构进入 UI 准备，不重复请求结构确认。线框审阅不自动确认素材公开条件、中文介绍、英文全文或正式品牌视觉。

## 已有输入与缺口

| 输入 | 当前依据与状态 | 对 UI 的影响 |
| --- | --- | --- |
| 页面与路径 | 六类页面、桌面／手机结构及浏览路径已形成并经用户审阅 | 保持页面职责，视觉探索不擅自改成单页或增加 Lab 首发 |
| 当前试验案例 | NED；个人品牌 IP 为原计划首篇，设计未完成 | 用 NED 验证样稿，正式上线顺序后续决定 |
| NED 内容 | 概述、分工、判断、四段成果、复盘；具体版本见资料卡 | 保留完整范围，不为短页面删掉状态 |
| 对外身份 | Migo 是品牌主体；“独立设计师”描述品牌身份，不等于已有正式工作／客户经验 | 介绍与能力表述须依据实际项目，文案待审阅 |
| 品牌资产 | 当前品牌资产清单未登记 Confirmed 视觉成品 | Logo、Beedog、字体、色彩继续 Pending，研究不产生定稿 |
| 双语 | 简体中文与 English；现有英文仅为结构草稿 | 同时考虑长度与断行，不把占位译文当正式发布内容 |
| 联系 | 正式渠道、具体合作方式待确认 | 保留入口，暂不编造邮箱或真实表单成功状态 |
| 素材公开条件 | 原图、产品资料与字体等仍需按用途核对 | 内部设计参考和正式对外发布分别判断 |

网站介绍草稿 [建议，待审阅]：**“Migo｜关注 AIGC 视觉与商业视觉实践。通过自主项目探索 AI 辅助创作、内容组织与设计判断。”** 不以使用工具推导能力等级，不虚构客户或商业效果。核心主张沿用“好奇探索，认真设计”。

与早期“呆萌”印象相比，最新品牌资料明确可以不可爱；Beedog 以动作和情绪为主，通常不说话。网站的 Playful Character 不预先等于卡通幼态、对话助手或大量弹跳动效。

黑黄、蜂巢、机械感来自用户新增候选灵感，尚未选为正式方向；本轮不写入网站正式色板或组件。NED 的暖色墙面和项目字体也不成为 Migo 全站规范。

## 样稿应回答的设计问题

| 方面 | 需要验证 | 通过依据 |
| --- | --- | --- |
| 首页层级 | 身份、专业方向与作品入口是否清楚 | 不依赖长动画或角色才能理解设计师主体 |
| 案例开篇 | 模拟性质、职责与成果范围是否易读 | Migo 与 AI 分工清晰，不把平台概念写成真实商业成果 |
| 成果区 | 图片、说明、章节与放大行为是否协调 | 原图比例与完整内容可达；手机不只把长图整体缩小 |
| 品牌辅助 | 角色与未来资产怎样接入 | 即使角色暂缺，主要阅读任务仍完整；角色不替代署名 |
| 双语与手机 | 标题长度、正文行宽、状态与导航如何变化 | 中英文内容身份一致，无重叠、遮挡或横向溢出 |
| 可维护性 | 网站界面与案例自身视觉怎样分工 | 更换案例不需要全站重设配色或复制同一长图模板 |

具体色值、字体家族及许可、间距、组件尺寸和动效参数留到样稿阶段记录为候选，并经实际素材与界面检查后调整。当前不以通用经验或本次小样本研究宣称已找到最优方案。
