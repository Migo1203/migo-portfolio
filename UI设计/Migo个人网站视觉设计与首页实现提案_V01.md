# Migo 个人网站视觉设计与首页实现提案 V01

**状态：待 Migo 选择设计方向；不是视觉定稿、UI 验收或网站开发授权。**
**整理日期：2026-11-26。** 来源为 Migo 提供的《Migo Personal Website — Visual Design & Homepage Implementation》提示词。此文保存其方向、范围和要求，并补充与已确认策略、网站信息架构和现有样稿的差异评审；不是逐字复制原提示词。

## 1. 提案想做什么

### 视觉方向提案

- 视觉概念：**THE QUIET EDITORIAL ARCHIVE｜安静的编辑式创意档案馆**。
- 方向优先级：Editorial → Quiet → Intellectual → Human → Playful。
- 预期气质：像持续更新的设计出版物和个人创意档案；大量留白、明确层级、文字与作品共叙事；趣味和 Beedog 只在局部出现。
- 设计系统候选值：Warm Paper `#F3F1EB`、Ink Black `#242522`、Stone Grey `#8A8982`、Dusty Blue `#899EAD`、Soft Orange `#D5A16F`、Paper Shadow `#E5E1D8`。候选字体为 Inter／Manrope、Newsreader、Noto Sans SC／思源黑体、IBM Plex Mono；12 栏桌面网格、最大内容宽度约 1360px、正文 680–760px、移动左右边距 20–24px、间距以 4／8px 为基准。
- 图形建议：细线、编号、几何图形、网格、抽象符号和编辑式分隔；减少渐变、玻璃拟态、大量圆角卡片、无意义阴影和装饰 3D。
- 动效候选：轻微 Hover、进入视口淡入、适量错位、柔和页面过渡、小幅 Beedog 动作；支持键盘和 `prefers-reduced-motion`，不接管滚动、不做鼠标跟随、不自动播放有声视频。

### 首页内容提案

1. **Navigation：** `MIGO.`；Works / Thoughts / About；候选中英切换。
2. **Hero：** `Think Clearly. Create Differently.`；`A curious mind. A creative world.`；`An independent creative practice exploring design, art and ideas.`。标题为视觉中心，可配一张作品或抽象视觉，不以角色主导。
3. **Selected Works：** 以编号、名称、分类、年份、主图和短说明呈现精选项目；采用编辑式图文，不做通用商品卡片。
4. **Latest Thoughts：** 展示 Observations、Ideas、Research、Experiments 的文章条目；不套普通博客模板。
5. **About Migo：** 以观察、理解、判断和创造介绍设计理念，而非简历列表。
6. **Beedog：** 只在适合的位置作为彩蛋，不能抢 Migo 或作品主体。
7. **Footer：** MIGO.、标语、社交入口、联系方式占位及年份；不伪造尚未提供的联系方式。

### 实施范围原意

提示词希望先完成视觉设计系统和完整首页、通用组件、响应式、基础交互、项目文档与检查；不开发所有详情页、文章系统、完整角色互动、CMS 或 3D。实际构建仍必须服从当前仓库状态、已批准技术范围和项目边界。**本次整理仅归档和评审，不代表开始 HTML 修改。**

## 3. 现有 Sommerseth 分析驱动首页样稿是什么

当前文件位于 AIGC 品牌项目：`作品项目/Migo个人品牌总项目/01_品牌设计项目/05_品牌识别/样稿/Sommerseth分析驱动首页_V01/index.html`。目录名称保留 V01，但这个单文件原型已经按网站导航 V02 扩为首页、Projects 档案、NED 案例、Contact 与未知路径；不能把它误认为早期的单屏 Hero 图，也不能当作正式站点。

它是纯 HTML、内嵌 CSS/JavaScript 的独立体验原型，不是 Astro／TypeScript／Tailwind 应用，也不属于网站独立仓库的正式发布源。具有响应式断点、移动菜单、hash 状态路由、浏览器历史、焦点和跳过链接、键盘 Escape 与减少动态偏好；NED 案例入口有 24 格图像拼贴转场。既有样稿说明记录了 1440、1024、768、390、320px 视口及关键路径检查。本轮另外实际打开原型，只对 1440×900 和 390×844 截取现有首页：无横向溢出；看到桌面首屏文字左、NED 图右，手机改为上下结构。该检查只说明本地样稿当前行为，不等于完整复测或验收。

### 可保留为基底的部分

- 已有真实 NED 资产、清楚的项目署名与“自发概念项目”事实标签；不会凭空造项目。
- 已有首页 → 项目档案 → 案例 → 联系路径，且已有移动菜单、访问性行为和减动效规则。
- 已有钴蓝、灰白、Geist 等参考站线索被封装在 CSS 变量中；样稿本身说明这些值是 Sommerseth 分析试验，不是 Migo 的最终 VI。
- 已有 Projects 与 NED 详情入口，以及独立保留 NED 暖色项目语境的边界。
- 已有带项目视觉的 24 格转场；可与新方案的轻量动效比较，不应默认删除或照搬。

### 当前首页可见的结构

`migo.` 顶栏 + Home / Projects / Contact → Hero（「让想法变成看得见的东西」及中文说明、作品和联系入口，右侧 NED 封面）→ 主题关键词索引带 → 深色 About → Selected Work（NED）→ Contact 提示 → Footer。单页 hash 原型另外承载 Projects、NED detail、Contact 与 missing 状态。

## 4. 两种方向的相同点与冲突点

| 比较项 | 现有 Sommerseth 分析驱动样稿 | 新 Quiet Editorial Archive 提案 | 判断 |
| --- | --- | --- | --- |
| 品牌位置 | Migo 是主品牌，NED 是自发概念项目 | Migo 是创意作者，Beedog 是局部角色彩蛋 | 可一致；遵守角色资产未定边界。 |
| 首页主任务 | 介绍 Migo / 引导看作品和联系 | 以标语、档案和思想内容建构创作者品牌 | 目标相容，叙事重心需重新排序。 |
| 视觉质感 | 亮白灰、强钴蓝、现代无衬线、圆角和较强 Hero 图像 | 暖纸、墨色、低饱和蓝灰与橙、出版式层级和更安静的节奏 | **主要风格冲突**；若采用新方向，应把现有颜色和 Hero 构图当参考实验而非必须保留。 |
| 首页内容 | About 和项目突出；当前有重复的 NED 封面使用 | 增加 Latest Thoughts，突出编辑式索引和文字内容 | 可增加思想层，但须有真实内容，建议先用一两个真实条目试验而不是做空列表。 |
| 导航 / 页面范围 | 首页、Projects、NED 案例、Contact、404 | Works / Thoughts / About；Footer 才提联系 | **信息架构冲突**；不能把 Contact 下沉、Project Detail 丢失。Thoughts 是品牌栏目，未必必须成为一级页面。 |
| 作品表现 | 大幅 NED 封面，已标自主概念 | 以编辑式布局介绍类别、年份、图片、短文 | 可兼容，可避免“商品卡片”，但 NED 自己的视觉 VI 应保留。 |
| 角色 | 目前没有角色露出 | Beedog 偶尔作为彩蛋 | 条件相容，标准形象尚未确认；当前不要生成占位角色图假装已定稿。 |
| 交互 | 已有项目图像拼贴式页面转场、菜单、历史与键盘逻辑 | 提议更轻的淡入淡出、滚动进入、微交互 | **动效风格冲突**；前者识别强，后者克制。建议比较“一次项目转场”与“普通浏览微动效”，不让每节都动画化。 |
| 技术栈 | 单文件可独立预览 | 目标描述通用组件、中英文扩展与完整首页实现 | 新提示词没有实际选定或核实框架。不得据此假设现有单文件或 Astro 生产站已经存在。 |

**结论：** 方案并非推倒重来。内容事实、作品优先和角色层级可保留；需要用户选择的是整体视觉重心、Hero 表达、首页内容节奏、主导航和转场动效。把新颜色套上原样稿并不能完整实现此方向；若保留原样稿全部钴蓝、圆角、Hero 构图和拼贴转场，也就没有真正测试 “Quiet Editorial Archive”。

## 5. 可行性与实施边界评估

### 可行

- 在现有 HTML 样稿上进行**隔离的首页视觉分支 / 对照版**，不必先搭正式网站框架；可复用它的页面结构、响应式、真实项目图和键盘／减动效逻辑。
- 先调整 CSS token 与 Home 内容呈现，保留 Projects、NED 详情、Contact 的可用路径。用项目自身 VI 呈现 NED，个人品牌页面用候选 Migo 设计语言。
- 通过同素材、同项目事实比较当前版与新方向，审阅留白、中文可读性、项目优先级、首屏身份、桌面／手机和动效偏好。
- 如果当前工作只限本地审稿，单文件可继续用；若未来要做双语、多项目和维护性升级，Astro 等技术规划可另行评估，不能把它与本次视觉对照绑成一次迁移。

### 先解决的实质限制

1. **候选色不能不经调整就作为正文色使用。** 按提示词给定的 `#F3F1EB` 背景计算，Ink Black 对比约 13.64:1，满足正文可读性需要；Stone Grey 约 3.11:1、Dusty Blue 约 2.46:1、Soft Orange 约 2.03:1。后几者若用于正常大小的文字／链接达不到 WCAG 2.2 AA 常规文字 4.5:1 的对比要求；即使大号字例外也要至少 3:1。可以保留它们作大面积形状、非文字标记或把文字色进一步调深，最后须按真实组合复测（WCAG 2.2，成功准则 1.4.3）。
2. **“Latest Thoughts”不能靠虚构填充。** 仓库有真实设计研究，可作为未来内容候选，但是否公开、整理成文章及用哪种日期，需按实际记录决定；暂时没有足量条目时，宁可做精选观察入口或暂不展示。
3. **Beedog 标准视觉未完成。** 角色定位已确认不代表角色形象、动画和风格已确认。当前可先留出位置、不显示角色，待角色资产完成再试。
4. **中英内容不只是切换按钮。** 官网 V1.1 的标语已确定，但主张的英文表达和整页翻译尚未确认。完成中英两套实际文案前不做假翻译或无效语言按钮。
5. **官网并未准备好开发。** 当前可验证的是 AIGC 仓库里独立 HTML 样稿；网站仓库仍是规划、线框和 NED 预览体系。不能把此原型称为生产网站或把单文件路线描述成已选技术架构。
6. **调色和字体可读性有替代成本。** 需核查字体许可、中英覆盖、加载体积和可靠回退；本轮没有安装或嵌入新字体。

## 6. 建议的最小评审稿（待用户批准，不是已执行）

### 先做静态视觉对照，不做整站开发

- **A｜现有基线：** 保留 Sommerseth 分析驱动的现有结构与主要视觉语言，仅作为对照。
- **B｜Quiet Editorial Archive：** 以 V1.1 主张／标语作为文案素材层级候选，建立暖纸与墨色为主的克制编辑排版；蓝灰／橙仅做小范围标记并检查对比；保留 NED 原图和其项目 VI；使用真实的项目类别、年份、简介与分工。
- **比较一致性：** 两稿使用相同 NED 封面、同一事实、同样的 CTA 与近似视口，不伪造 Thought 文章。首轮先不展示未完成的 Beedog；动效先用静态构图或录屏单独比较，避免同时改变过多变量。
- **样稿导航：** 先兼容已确认 Home／Work（或 Projects）／About／Contact 和 Project Detail；Thoughts 可暂作首页章节或日后扩展，不在用户确认前顶替现有主导航。
- **首屏文案层级候选：** 品牌标语 `Think Clearly. Create Differently.` 不单独承担身份说明；另配清楚的 Migo 身份、已定中文主张或身份说明、`查看作品` 入口。具体中英文文案须审阅，不写入正式资产。
- **评审题：** 第一眼是否知道这是 Migo 的个人创意作品档案？能否直接找到作品与联系？是否仍能迅速了解真实项目和 Migo 实际贡献？“安静”是否增强作品阅读，而不是变得冷淡、空旷或像图书馆模板？手机上标题、图和项目事实是否自然？

**推荐：** 若目标是判断新方向本身，B 版需要勇于区别于现有钴蓝 Hero，但保留可用路径、内容事实与 NED 自身 VI。不要先定 Logo 或 Beedog，也不要在未看对照前把候选暖纸色宣布为正式品牌色。

## 7. 需要 Migo 作的决定

1. 是否批准在独立复制样稿中制作 **B｜Quiet Editorial Archive** 静态首页对照，A 版保持原样？
2. 是否同意第一轮暂不出现 Beedog（角色形象尚未确认），避免用假图代替？
3. Thoughts 首轮是否作为首页的一个轻量内容区候选，还是暂时只保留作品与 About？没有真实文章前不会生成虚构内容。

上述选择只决定下一轮审阅稿，不等于品牌视觉定稿、正式官网实现、Pages 发布或替换现有预览。网站仓库有先前本地 NED 改动，后续处理须另行隔离和核对，不混入品牌提案同步。
