# NED V03｜品牌故事网页展示规划

日期：2026-11-22。仅接入独立 V03，范围不含个人网站发布源、原 Listing、既有高级 A+ 及 Banner。

## 页面顺序与分工

**八图总览（可进入 Listing） → 品牌故事 → 高级 A+**。参考 Amazon 将 Brand Story 与 Premium A+ 作为不同内容类型的设计；本次按用户指定顺序排列，不模拟平台后台或上架。品牌故事介绍 NED、选品审美和居家生活；高级 A+ 保留对 Eric 的操作、场景和规格说明。没有额外的品牌氛围大屏，也不重复作品集长图中在过去顺序下使用的过渡段。

| 屏幕 | 展示 | 交互 |
| --- | --- | --- |
| 桌面（≥1152px，默认字号） | 直接使用原 B00 桌面图文成品：居家背景与四张卡完整同屏，和 A+ 左右对齐 | 不加无意义的翻页按钮；可直接滚到下一节 |
| 手机及窄屏 | 依次复用 B01 认识品牌、B02 设计风格、B03 日常生活、B04 品牌问答四张独立手机图文成品 | 一次一张；标签直达、左右箭头、横滑。不自动播放；支持键盘。关闭 JavaScript 后按顺序阅读 |
| 文字无障碍 | 英文按原稿重录为可选读的 HTML 文本，不覆盖图中文字 | 标题和各状态有可理解的名称，可展开文字版 |

## 原稿和视觉边界

- 原稿：NED 作品集「成果展示 V04 / 03_品牌故事 / 01_成品与预览 / 逐模块预览」的 B00–B04。同组原 SVG 仍是可编辑源稿；网页仅输出同尺寸 WebP，不改原稿，不重排、调色、叠罩或生成新图。
- 标题、外侧暖色底及导航视觉与 V03 现有高级 A+ 对齐；模块内部颜色、留白、照片及英文按原成品。不要将桌面四卡硬缩到手机，也不把四张手机状态连成长图。
- 品牌内容原样复用，属于作品集创作草案，不是 NED 官方文案。沿用原项目基于 NED 官网 About Us 留存的英文草案；不因品牌创立地推断商品产地，不新增合作、历史或性能宣称。
- 验收：页面顺序和嵌入边界；五张原图的引用、比例和可读性；手机箭头／横滑／键盘／无脚本降级；原 A+ 和八图 Listing 的交互不变。

## 本地制作与验证

- 独立 V03 已按规划接入，锚点 `#brand-story`，紧接八图总览、紧邻高级 A+；站点嵌入模式不显示品牌故事。原发布 HTML、A+ 的结构和样式、八图与 Listing 实现均未改动。
- 复用 B00 桌面图（1464 × 625）和 B01–B04 手机图（390 × 625）。五张 WebP 合计 362,756 字节；按原比例展示，窄屏画幅最多 390px。无网页遮罩、文字覆盖或图片滤镜。
- Chrome 核验 1440、1152、1140、1024、768、390、320px，以及 390px 下 200% 根字号：断点切换、五图解码与比例、对齐、无横向溢出、四张移动卡的标签／箭头／键盘及横滑、可展开文字版通过；无脚本时四张按顺序显示。原 A+ 轮播及 Listing、八图放大复测通过。
- Impeccable 检测器报容器边距提示；浏览器实图复核，标题及图文成品遵循 V03 两侧边距，没有正文贴边。
