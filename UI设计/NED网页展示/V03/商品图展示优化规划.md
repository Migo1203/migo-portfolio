# NED V03 商品图展示优化规划

日期 2026-11-19 · 阶段为局部改版，方案待浏览器验证与用户审阅。

## 版本比较与采用方向

| 样稿 | 实际展示方式 | 本轮用法 |
| --- | --- | --- |
| V01 | 两张代表大图与文字说明，下方提供八张缩略图。 | 保留每张图对应一个沟通任务的思路，沿用 V03 已有的单图说明。 |
| V02 | 桌面四列、手机两列的八图网格，图片可放大。 | 借用整组网格，供访客快速扫读八张图。 |
| V03 A | 桌面左侧缩略图、中间大图、右侧文案与切图操作。 | 作为默认浏览方式，保留商品图在 Listing 中的阅读情境。 |

在本地浏览器对照了 1440 px 与 390 px 两种宽度。1440 px 时，V03 当前大图约 604 px，V02 单格约 302 px。V03 的主要待解问题是缩略图不足以帮助访客快速读懂整组内容，手机上单图说明也离大图较远。

## 版式与操作

1. **桌面单图**保留 16∶9 模块、竖排缩略图和完整方形大图。右栏保留原引言和商品名，把当前图片标题、介绍和切图操作放在一起，并加入口「查看全部 8 张」。
2. **整组浏览**在同一区域展开网格，桌面四列，手机两列。沿用八张图的原顺序、标题和介绍。点选任意图片回到对应大图，「返回单图」恢复先前选中的图片。
3. **手机单图**按大图、当前图说明与切换、缩略图的顺序排布，当前图信息紧接大图。引言与商品名放在图片区后，模块高度随内容增长。
4. **访问与回退**为网格入口、返回和点选过渡设置清楚的键盘焦点。保留查看原图入口。脚本关闭时页面提供带介绍和原图链接的整组网格。
