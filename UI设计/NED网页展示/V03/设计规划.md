## 2. 现状与问题

此前查看的 V02 源样式中，桌面端标题区存在沙色面板；较窄断点又将图片放到文字之后。两种处理都优先保障了可读性，却削弱了封面图文的整体感。

原规划担心旧封面内嵌文字在手机缩小时难读，并与网页标题重复。V03 保留“文字使用真实 HTML”这一正确方向，但不再把“文字可读”与“图文分区”绑定。

注意：本地 V02 单文件内还包含额外布局变体。实施前必须核对实际生效的样式层叠、布局初始化和脚本，不能只删除某一条媒体查询就宣称问题解决。

## 3. 整体设计方向

**一张完整封面、一个主标题、一组轻量身份信息。**

- 图片负责场景、产品和氛围。
- 主标题负责项目识别，保留 V02 的字体表现与入场节奏。
- 品牌和类别信息退到次级，不与产品名争夺焦点。
- 全部文字为可选择的 HTML 文本；不把带字封面截图当最终背景。
- 封面内部不使用实色文字卡片；必要时使用低强度局部渐变。

## 4. 三项核心设计决策

### 4.1 底图：沿用同场景无字原图，按设备重新构图

**核心判断**：先解决图片与文字的空间关系，不为改版而重新生成场景。

**规划基线**：优先寻找图 1 同场景无字原图，并检查 V02 的 `封面_原场景裁切.webp` 是否为可用来源；文件名不代表它必然满足分辨率和构图要求。

执行顺序：
1. 核查无字原图、分辨率、产品完整性和来源；对照参考图确定同场景关系。
2. 桌面端优先左文右灯，文字安全区起始按可用画面左侧约 35%–40% 试排，不把比例视为固定规范。
3. 手机端优先制作同场景竖向裁切：上部墙面留文字，下部或右下保留台灯主体。
4. 原图无法同时容纳标题和产品时，先调整裁切、标题位置及封面高度，再考虑同场景扩图或另制竖版。
5. 若仍无法满足，暂停并提交构图问题给用户选择；不得自动回退到上文下图的分离结构。

**取舍与风险**：横图不能靠单一 `object-fit: cover` 适配全部屏幕；扩图不得改变灯具比例、结构和场景光影。不优先擦除带字图片作为底图，也不将强遮罩作为补救手段。

### 4.2 标题：Eric Lamp 为唯一主标题，NED 为品牌信息

**核心判断**：品牌名、产品名、设计类别应形成层级，而不是同字号并列。

建议信息结构：

| 层级 | 内容 | 呈现方式 |
| --- | --- | --- |
| 品牌 | NED；若已有可用正式标识则使用该资产 | 小尺寸，位于标题上方 |
| 类别 | E-COMMERCE VISUAL DESIGN | 轻量眉题，与品牌组合 |
| 主标题 | Eric Lamp | 唯一 h1，封面最主要文字 |
| 项目说明 | 无线氛围灯的电商视觉设计 | 次级正文，一至两行 |
| 项目属性 | 自主概念项目 · AI 辅助制作 | 辅助说明，清晰但不抢主标题 |

- 宽屏优先一行 `Eric Lamp`，空间不足时按词排成 `Eric` / `Lamp`。
- 换行仅用于视觉排版，文字语义与可访问名称保持 `Eric Lamp`，不得出现 `EricLamp` 或 `NEDEric Lamp`。
- 先沿用 V02 标题字体和字重；字号随构图调节，不为最大字号牺牲产品识别。
- 首屏最多保留一个低强调“查看成果”入口；若与构图冲突可移至封面边缘，正文原锚点不改。

**取舍与风险**：`Eric Lamp` 比参考图的 `Eric.` 更长，但产品含义更明确。不得通过把 NED 放大、增加重复标题或压住灯具来弥补信息焦虑。

### 4.3 顶部小字：保留角色，简化措辞

**核心判断**：保留“品牌＋设计类别”的编辑感，不逐字复制参考图。

- 封面内使用 `NED / E-COMMERCE VISUAL DESIGN` 的品牌与类别关系；斜杠仅表示关系，不强制作为画面字符。
- 有正式 `ned.` 标识则使用已有资产；无资产时使用普通 NED 文本，不临时拼造相似手写标志。
- 眉题与主标题左对齐，位于封面内部，不替代网站导航。
- 网站 Migo 是作者身份，NED 是案例品牌身份；两者在空间和字号上区分。
- “亚马逊美国站展示语境”保留在项目背景中，不重复堆在顶部。
- 手机端允许类别换行或隐藏，但不得把项目的设计性质与自主项目说明全部隐藏。

**取舍与风险**：顶部内容过多会再次拥挤；不以 Amazon 官方合作或委托项目口吻呈现。项目属性说明必须在正文与首屏保持一致。

## 5. 响应式与可读性原则

| 宽度区间 | 封面策略 | 文字策略 |
| --- | --- | --- |
| ≥1200px | 横向场景，左文右灯，保持单一画面 | 主标题优先一行 |
| 640–1199px | 逐级调整焦点、内容宽度和留白；不在 1023px 自动分家 | 允许按词两行，辅助信息收紧 |
| <640px | 同场景移动端构图，仍保持图文叠合的完整封面 | 适当减字号，安全边距优先，不强迫横图桌面版等比缩小 |

以上为设计初始区间，最终按实际内容碰撞调整，而不是机械沿用断点。

- 封面高度参考可视窗口，但不锁死为单一比例；短屏和文字放大时允许容器增长。
- 导航可作为独立站点界面保留，但不得与封面内标题形成另一块大型说明区。
- 导航、标题、说明互不遮挡；无横向滚动，底部内容不因固定高度被裁掉。
- 优先深色文字配明亮墙面；对比不足先调整位置和裁切，再使用低强度渐变。
- 普通文字对比目标至少 4.5:1，大号文字至少 3:1；须在实际图片、各裁切和动画初末状态检查，不能只测纯色底。
- 图片加载前用协调浅色占位，确保文字仍可读。

## 6. 动效保留与调整

1. 复用 V02 标题遮罩上移的表现，沿用现有字体，不改为打字机、字符乱序或循环动效。
2. 按最终标题排版适配遮罩包装；检查字形下沿、行高及缩放后裁切。
3. 品牌、类别和说明以轻量淡入跟随；不让所有小字逐字播放，也不引入重复入场。
4. V02 背景约 1.05 → 1 的缩放作为候选保留，优先级低于标题动效。若起始缩放遮住台灯或破坏文字安全区，应减弱或关闭背景动效。
5. 复用时核对原脚本选择器、初始化顺序及安全回退，不直接假定原脚本与新 DOM 无缝兼容。
6. `prefers-reduced-motion`、`data-motion="off"` 或脚本不可用时，全部文字和图片直接可见；不得永久透明。

## 7. 后续实施步骤（待用户授权执行）

1. **素材核查**：定位无字原图、正式品牌标识、现有字体和动效源文件；记录缺失项，不编造资产。
2. **静态构图确认**：先给出桌面与手机各一张构图预览，确认台灯完整性、标题位置与对比度，不先做整页。
3. **独立建立 V03**：以核实后的 V02 实现为基础，仅改首屏；保留 V01、V02 与正文，清理或隔离冲突的 hero 规则。
4. **动效接入**：复用原标题效果，验证换行、背景缩放、减少动效和脚本失败回退。
5. **响应式验收**：按下节检查尺寸与状态，修复断点附近跳变。
6. **交付与归档**：用户确认首屏后再归档 V03 HTML、必要素材及变更记录；是否发布另行决定。

建议 V03 后续目录为 `设计规划.md`、页面源文件及按需使用的素材目录；本轮只创建规划文档，不建立空页面或伪完成产物。
