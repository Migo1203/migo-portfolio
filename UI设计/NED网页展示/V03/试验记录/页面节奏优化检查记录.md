# NED V03 页面阅读节奏优化检查

日期：2026-11-20
对象：独立 V03 A 样稿；不含个人网站融合副本。
环境：本地 HTTP、Chrome headless、Playwright；用于本地布局与交互复核，不代表用户视觉验收或正式网站验收。

## 本轮实施

- 项目背景移除至少占满一屏的高度要求，收紧任务正文行距，拉开概述与分工的层级。
- 设计说明按内容自然增长，章节间用更明确的间距区分；昼夜场景仅因原图构图保留独立宽幅空间，其他章节不统一套 16:9。
- 产品全貌与操作近景继续按不同素材比例呈现，保留灯具完整轮廓与手部操作细节。
- 参考色场景不再使用整屏最低高度，桌面场景框改为宽幅比例、手机采用较接近原图的横幅比例。
- 八图总览继续使用原顺序和方形商品图：桌面四列两行、手机两列四行；收紧标题到网格的距离，微调行距及图注留白。保留点击放大与 Listing 切换。
- Listing 主图继续按方图完整呈现；不把长 Listing 内容限制在单屏画布中。

- 检查的是视口溢出、图片加载、主要比例及交互；不代表色彩、文案或最终审美已由用户确认。
