# NED案例页方向约定

模式：Experience，阅读为辅。用户已确认沿用NED作品、自主模拟与AI协作事实；本次范围是背景、策略和配色展示的深度优化。2026-11-15选择code-first。

## Direction contract

THESIS：让一盏灯所在的生活空间，连接“为什么这样设计”与“具体做出了什么”。把背景与策略融入作品，不再在白卡片中插入缩小长图。

OWN-WORLD：沙灰作为主阅读底，深胡桃承担背景与色谱的深色域，炭灰支撑夜间层次，陶土形成局部暖色。骨白是少量光感与原作品表面。开放式排版、真实照片和直角图像，没有重复圆角卡片。

STORY：首先辨认Eric与成果；读懂自主电商练习的任务与分工；通过日夜、轮廓与内容分工理解三个判断；浏览原作品，再了解边界和下一步。

FIRST VIEWPORT：顶部是Migo文本导航；NED Eric Lamp与电商视觉标题居左，大幅原客厅场景占据主要面积。桌面文字在图片安静区域旁的实色版面，手机先读标题再看保留产品的场景。成果入口在首屏内。

FORM：参考色不是五颗装饰圆点，而是由大场景、五块不同职责色域及材质局部构成的编辑画布。色号、RGB和用途为可选择文字；用户可点按查看用途。本次依据new-work.md“Extend an existing surface”与“Never run the script for a local extension or a precisely specified narrow request”免于concept-seed／方向轮转：用户明确要求“参考项目里面的视觉和作品集展示”“特别是项目背景介绍和设计策略”“减少白色块”“项目参考色部分介绍希望用参考图的设计但不是完全照搬”。原NED五色、图片与V01案例结构已有，本次是既有案例的局部扩展，不另造世界或虚构seed。taste动效抽取seed37beea38仅属于taste，不冒充Impeccable方向种子。

MOTION：官方hero一次轻入场；官方picture-develops仅用于策略主图。其他动作来自明确操作：场景切换、色彩选择与原图浏览；无循环背景、无滚动劫持，reduce与无JS保持静态阅读。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
