# NED案例页产品事实

## Platform

web

## Stack

沿用现有审阅稿：静态HTML、CSS、JavaScript。用户于2026-11-15明确选择直接制作可操作HTML，再用浏览器审阅。正式网站预期Astro，不在本轮初始化。

## Users

用户已确认：招聘方优先，兼顾商业合作方。读者需要判断Migo的方向选择、信息组织、视觉判断及AI协作能力。

## Product Purpose

把已有NED电商视觉项目转为可阅读、可浏览成果的网页案例。先看真实成果，再理解项目背景、本人贡献与设计策略。

## Positioning

Migo的自主电商视觉练习；NED Eric Lamp是研究对象。不是NED官方商城、品牌委托或真实亚马逊上架案例。

## Operating Context

既有网站规划、线框第三版与NED网页展示V01提供结构输入；AIGC中的NED项目规划和V04原作品集为内容与视觉依据。所有源文件保留。

## Capabilities and Constraints

- 本轮交付V02规划、案例页样稿、桌面与手机预览及检查记录。
- 保留项目背景、分工、设计判断、四类成果与复盘；不虚构销售、转化或投放数据。
- 主要中文；英文为审阅草稿，不代表终审翻译。
- 保留8张商品图完整浏览及A+、品牌故事、Banner完整来源入口；代表模块不能冒充整套已重制。
- 不改已有Pages发布源，不自动提交、推送、部署。

## Brand Commitments

Migo是设计师主体；Beedog是品牌角色。NED项目参考色不等于NED官方VI，也不等于Migo品牌色。用户要求减少非必要白色块，加强作品自身氛围，并借鉴所附配色参考图的组织方式而非照搬。
