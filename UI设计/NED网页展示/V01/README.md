- 点击两张代表成果、缩略图或“浏览8张完整商品图”，查看全部商品图；支持左右键、关闭、Escape、焦点返回及原尺寸链接。
- 首页的作品入口进入案例，“关于／联系”有实际内容落点；联系方式待确认，没有伪造邮箱或表单。

## 这次真正设计了什么

- 从原源稿复用无文字客厅场景，将项目名、简介、职责与说明变成网页文字；手机重新组织文字与取景，作品不随整张封面一起缩成小字。
- 建立连续的场景开篇、紧凑项目事实、个人／AI分工、图文设计判断、商品图查看与复盘，使用不同尺度表达内容职责。
- 全站`--site-*`和案例`--case-*`变量分开；NED暖色与产品场景保留，Migo未来VI可按层次接入，并重新检查字形和对比度。
- 实际使用Inter与Noto Sans SC字形子集，保留OFL和来源；字体、色彩与组件只属本样稿候选，不是Migo品牌规范。

本轮完成的是关键区域与代表成果段的UI候选。商品图八张均可查看；高级A+、品牌故事、Banner保留完整原稿入口，尚未逐一完成网页重编排。四类成果的原始范围不缩减，不把原稿链接等同于完成N04。未制作Logo或角色，未初始化正式Astro网站。

## 后续怎样改

[页面模板](制作资料/页面模板.html)保存清晰可编辑的HTML／CSS／交互结构；[生成脚本](制作资料/生成样稿.py)保存英文草稿、素材引用和便携打包逻辑。Python加fontTools可从既有素材重建，不联网、不改素材原件。本轮已重建并验证与验收HTML逐字节一致。新增中文字符时脚本会提示更新字体子集，不能以系统回退冒充自托管字体完整。

先审阅整体视觉、信息顺序、手机节奏与网页／作品的关系，再根据反馈进入完整案例编排。本次按用户要求将V01与V02纳入GitHub归档提交；未部署，线上仍为第三版。两版导航见[版本入口](../README.md)。
