| 优先级 | 本清单中的含义 |
| --- | --- |
| P0｜基础 | 建议首版必须保证的访问、阅读和操作行为；视觉动画可以省略 |

| I10 · P0 | 访问不存在的页面或案例 | 显示可理解的未找到信息和有效首页／作品入口 | 用户主动选择返回，不自动倒计时跳转 | 中英文可理解；减少动态时静态展示 | 原型未知 page 参数显示 404；真实 HTTP 404、语言回退和托管路由未实现 |
| I11 · P0 | 使用 Tab、Enter、Space、Escape 等键盘操作 | 可见焦点；链接和按钮语义清楚；图片查看层的焦点留在当前对话框 | 关闭浮层后回触发处，不产生无法退出的焦点陷阱 | 触摸不触发悬停假状态；减少动态时焦点仍清晰 | 原型已有焦点样式、跳到正文入口及部分操作检查；完整键盘与读屏测试未完成 |
| I12 · P0 | 改变窗口宽度、旋转设备或放大文字 | 内容重排、不整体缩小；入口仍可见，不以桌面悬停为手机前提 | 保留页面身份；若切换布局时隐藏了已聚焦入口，焦点需转到等效可见入口 | 真实手机与不同文字长度均需检查；减少动态时避免布局位移动画 | 原型已有自适应重排和菜单切换；跨断点焦点、文字缩放、浮层状态保留仍待验证 |

### 需要在设计中明确的边界

- **菜单与图片查看层分开处理：** I03 首版建议仍用行内展开，不直接复制 Dennis 整屏菜单。如果后续选择整屏／侧边覆盖菜单，需要另外定义关闭按钮、Escape、背景不可操作、滚动恢复和焦点管理，不能只增加滑入动画。
- **语言缺译方案 [待讨论]：** 原型有两种草稿，不代表正式译文齐备。建议未完成英文的案例保留同一项目说明与中文入口，不跳到无关案例；发布或延后发布需结合内容计划决定。
- **作品完整性：** I05–I06 继续遵守 NED 的 9 图组、44 项范围，不能为简化动效删除手机状态或只留代表图。真实作品的比例、长图缩放、触摸缩放与图像清晰度需另测。
- **浏览器后退：** I02、I04、I07 的位置保留是待验证要求，不能因为存在返回链接就写成已完成。正式路由实现后同时检查 URL、语言、章节和滚动位置。

## 4．动效参数候选 [待验证]

这些数值是 Migo 下一轮样稿的比较起点，不是从 Dennis 测得的参数，不构成品牌标准，也未写入 CSS 或原型。

| 用途 | 候选范围 | 约束 |
| --- | --- | --- |
| 颜色、边框和下划线反馈 | 100–160ms | 输入反馈立即开始；焦点不能因等待动画而不可见 |
| 菜单轻量淡入 | 160–240ms | 支持中途反向操作；是否添加由样稿比较决定 |
| 图片查看层淡入／淡出 | 120–180ms | 关闭操作立即生效，焦点与滚动恢复不依赖长延迟 |
| 入口缩略图轻微缩放 | 160–240ms，最高约 1.02 倍作候选 | 不造成布局抖动；图片重要信息完整，不用于正文长图 |

建议先比较简单 ease-out 与无动画，暂不引入弹簧、循环弹跳或整站动画库。首版章节跳转默认即时；如后续加入平滑滚动，必须有减少动态效果的即时替代。

减少动态效果使用系统偏好 `prefers-reduced-motion` 作为后续实现输入：取消缩放、位移、自动移动和跟随；菜单、图片层与导航仍能直接操作。该分支尚未在原型实现；不要把线框没有动画视为已完成偏好检测或无障碍验收。
