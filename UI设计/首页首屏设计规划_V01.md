# Migo 首页首屏设计规划 V01

2026-11-27 · 规划稿，供下一轮视觉试排和浏览器检查使用。

## 目标与设计基底

沿着现有 A 版的年轻感，把首页第一屏做成 Migo 的品牌封面。访客先看到 Migo 的名字、标语和原创视觉，再通过「查看精选作品」进入下方章节。首屏画面不放项目封面、项目名称或项目卡片。NED 保留在精选作品和现有案例入口中，案例继续使用自己的视觉风格。

A 版已有灰白、黑与蓝的高对比、醒目的大标题和简洁导航，首轮用这些作为试排起点。现有 `migo.` 字标、蓝色、字体和新图形均为样稿素材。品牌标语的文字已确认，具体断行、语种、字体和使用位置在本轮试排中比较。

## 首屏构图

| 区域 | 首轮设计 | 作用 |
| --- | --- | --- |
| 顶部 | 左侧放 `migo.`，保留 `Home / Projects / Contact`。手机沿用可展开的菜单。 | 识别站点，保留项目档案与联系入口。 |
| 主视觉 | 布在中部偏右。用几块错位的几何块组成原创图形，只在一处加选区边线和少量节点。选一个节点用蓝色呼应字标句点。 | 借画板与选区表现创作过程，让同一蓝点在字标和主图里形成可识别的联系。 |
| 文字 | 桌面左下排两行 `Think Clearly.` / `Create Differently.`，以「独立创意实践」作为简短的身份说明试排。 | 标语建立主要阅读层级，身份说明补充 Migo 是谁。 |
| 底部 | 把现有分类条的位置改为单一文字入口「查看精选作品 ↓」，保留底边呼吸空间。 | 链接到首页 `#work`。顶部 `Projects` 仍进入完整档案，`Contact` 仍负责联系。 |

桌面用大字与图形的错位建立张力，给字母和标点留完整的阅读区。绘制重点是几何块的比例和选区落在哪里。首版只测试这组关系，坐标、计数与工具图标留到有明确页面用途时再评估。图形用静态状态先比构图。若加入动效，只试一次由节点到图形的短揭示，使用常规网页元素和轻量实现。减少动态效果时直接显示完整图形。

本方案微调了[全站导航规划 V02](../网站导航规划_V02_讨论稿.md)中的 Hero 入口配置。首屏内容区保留一个作品入口，联系由顶部导航承接。首页长页仍按 Hero → About → Recent Projects → 联系与页脚组织，作品入口可直接跳到 Recent Projects。

## 满屏与响应式规则

A 版桌面首屏的最低高度用 `min(790px, calc(100svh - 76px))`。视口升高时，这项最小高度仍受 790px 限制，实际高度也受内容影响。导航与分类条分别占空间，所以较高窗口可能在第一屏露出 About。A 版右侧图片的 4:3 比例仅适用于那张项目卡片。

- **首屏尺度随浏览器视口变化。** 导航、品牌画面和底部入口共享一张全宽背景，合计至少占一个视口。后续可用 `min-block-size: 100svh`，提供 `100vh` 回退，并让导航高度参与正常布局。画面可以铺到窗口边缘，文字与导航仍按统一的左右边距对齐。
- **桌面设计以 1440 × 900 CSS 像素试排。** 在更宽的窗口放开图形和留白，限制大字最大尺寸。矮窗口先收图形与留白，内容需要更多高度时允许首屏自然增长。
- **手机重新排列。** 按「导航 → 标语与身份 → 主图 → 作品入口」阅读。几何块缩成一幅完整构图，允许标语按窄屏自然换行，检验最窄屏和放大文字时入口仍可触达。
- **参考截图只用于构图判断。** Sommerseth 可看全幅主视觉和底部入口的关系，HAOQI 可看网格、图形和大字怎么共处，Caleb Raney 的 Allie Orth 是案例封面，可看图形与标题怎样分配留白。截图未提供各站的断点或高度实现。

## 实施顺序与验收

1. 以 A 版为对照，先做一张 1440 × 900 桌面和一张 390px 宽手机的静态构图。先看字标、标语和图形的主次，再看蓝点是否有识别作用。
2. 构图确定后，再把首页 Hero 做成可预览的自适应样稿，接通 `#work` 和既有导航。如需试动效，在静态样稿可读后加入轻量揭示。
3. 检查 1920 × 1080、1440 × 900、1366 × 768、768px、390px 和 320px 宽视口，并测试键盘操作与减少动态效果。常规桌面窗口中，品牌封面占完整首屏，About 从下一屏开始；矮窗、旋转或文字放大时允许自然滚动，文字不遮挡、无横向溢出。首屏看不到 NED 封面或其他项目卡片，作品入口准确跳到精选区，项目档案、联系和手机菜单可访问。

待首轮看稿确认：图形块的比例、选区节点的密度、标语排版和身份说明文案。此次交付为规划与设计索引，预览制作和视觉审阅属于后续阶段。
