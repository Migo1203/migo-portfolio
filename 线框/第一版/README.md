# 第一版线框｜Migo 网站与 NED 试验

日期：2026-11-09。状态：12 份基础线框初稿已制作，待用户审阅。依据：用户确认“按该内容骨架和范围推进”。这次确认允许开始 Wireframe，不表示本轮制作的线框已经验收，也不表示 UI、正式网站实现或上线已获确认。

## 如何查看

1. 打开[交互线框审阅稿](线框审阅.html)，默认展示 NED 详情。顶部切换页面、桌面／手机和中文／英文草稿，可选择适应窗口或原始尺寸。
2. 若当前文档查看器不能执行 HTML，下载该 HTML 后用浏览器打开，或直接查看下面的 12 张静态长图。[线框总览](线框总览.png)只截取首屏，用于对照页面，不代表完整内容。
3. 从首页点击“查看作品”→ NED → 关于／联系，检查已确认的浏览路径。NED 章节导航可跳转，图片占位可打开大图占位并切换同一图组的前后项。

无需安装项目依赖。开发环境如限制直接打开本地 HTML，可从仓库根目录临时运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/线框/第一版/线框审阅.html`；仅用于本机审阅，不是部署。

## 操作与状态规则 [本轮线框建议]

- **导航：** 桌面导航直接可见；手机通过“菜单／语言”展开，同一页面可以切换语言。案例底部提供返回作品、关于和联系。
- **长案例：** 顶部章节目录允许跳过已理解部分；所有四段内容在正文保留，放大查看后可回到当前图位。正式图片加载策略留给实现阶段。
- **放大：** 原型演示模态层、同组前后项、关闭／Escape 和焦点返回。实际素材、触摸缩放、图片下载与实际大图性能尚未实现。
- **双语：** 两种草稿按相同案例身份切换；英文顶部明确标为草稿。正式缺译策略建议停留在当前项目并提示“英文准备中”，保留中文入口；该规则待用户选择，原型不冒充正式翻译已完成。
- **联系：** 缺少真实渠道时显示待补充并禁用操作，无虚构邮箱、表单、提交成功或自动回复。
- **404：** 展示错误页的结构与有效返回链接；并未实现真实托管环境的未找到路由。原型中未知页面参数回到默认 NED，实际网站不得直接沿用该审阅工具行为。
- **品牌 IP：** 当前作品列表不提供未完成品牌项目的伪成品入口。未来共用概述、职责、判断、成果和复盘字段，成果按品牌项目内容组织。

本地浏览器检查与实际导出范围见[检查记录](检查记录.json)。检查确认原型能否工作，不代替用户验收；不将其写成正式网站性能、SEO 或可访问性达标结论。

- [ ] NED 中能否快速理解项目性质、个人贡献和 AI 参与？
- [ ] 设计判断在成果之前的篇幅与顺序是否合适？
- [ ] 四段完整成果是否容易找到，章节导航和放大查看是否清楚？
- [ ] 首页与列表能否引导进入案例，关于和联系入口是否明显？
