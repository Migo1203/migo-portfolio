## 两种预览方式

打开顶部“页面与预览设置”即可选择页面、模式与语言草稿：

- **浏览模式（默认）：** 页面背景铺满窗口；内容区最大宽度和内边距用于阅读，不是灰色外框。改变窗口宽度会重新排版，而非整体缩放；无需手动指定手机。
- **画布模式：** 固定桌面 1440px 或手机 390px，带灰色画布，支持适应窗口／原始尺寸，方便对照。

工具条不属于正式网站主导航。原型中的 `mode=canvas` 仅用于不含工具条的固定尺寸截图。760px 是本轮验证手机布局的临时切换点，1280px 是内容区的线框上限，均不是已确认的正式 UI 标准。

## 内容与交互边界

- NED 保留“概述 → 我的工作与 AI 协作 → 设计判断 → 四段完整成果 → 简短复盘”，9 个图组共 44 个占位项，与[第一版范围](../第一版/README.md)一致。版本与个人分工继续以[案例资料卡](../../文档/首篇案例资料卡.md)为依据。
- 首页及关于页文案有针对性的草稿调整，不将自主项目写成真实客户委托；深圳 AIGC／视觉岗位方向来自[现有 UI 简报](../../UI设计/UI设计简报.md)。完整履历与对外介绍仍待审阅。
- Beedog 只保留未确认的形象位置；字体、色彩、Logo、角色与正式视觉继续 Pending。没有生成品牌图或接入参考网站的资产。
- 中英文切换保留当前页面身份和预览模式；英文仍为结构草稿。联系渠道未补齐时按钮禁用，无虚构表单或成功反馈。
- 未知 `page` 参数进入原型 404，可返回首页；这不验证正式静态站点的 HTTP 404 路由。
- 第一版文件保留不变，第二版另存；网站预览入口按本次发布更新，不覆盖既有研究或设计源文件。

## 建议审阅顺序

1. 默认首页：能否理解 Migo 的方向，是否方便直接进入关于和作品？
2. 从导航进入关于：是否仍需先看案例，或是否可以独立理解个人工作方式？
3. 作品 → NED：面包屑和栏目状态是否清楚，完整成果及 AI 分工是否易找？
4. 缩窄窗口或用手机打开：菜单、单列内容、双语和图组关闭返回是否清楚？
5. 打开画布模式：理解这里的灰色区域属于尺寸审阅工具，而非正式网站样式。

浏览器检查通过不等于用户验收；最终 UI、素材公开条件、正式译文和联系信息仍分项确认。
