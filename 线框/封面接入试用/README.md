## 检查与边界

[检查记录](检查记录.json)：Chromium桌面1440px／手机390px模拟，覆盖首页、列表、详情的实际图片解码、4:3比例、无页面横向溢出、卡片进入详情、查看层关闭／焦点循环／返回、英文替代文字、减少动效及退出模拟恢复真实封面。额外故意破坏查看层图像数据，检查实际解码失败提示；原图链接在新标签页实际打开并解码。正常检查无脚本错误、HTTP错误或外部资源请求。

已实际查看首页桌面卡片与手机查看层截图；截图不代表所有字体、手机或浏览器均通过验收。原版第三版HTML及WebP哈希保持不变。初制和修复时只保存在本地；2026-11-15用户要求将本试用稿与相关记录推送GitHub，见[归档授权](../../网站决策日志.md)。既有Pages仍发布第三版，本次不切换发布来源或部署。用户尚未验收本次封面显示、页面布局或最终UI。

## 单文件预览修复

用户截图显示封面破图并露出替代文字。此前验证只覆盖完整仓库内的HTTP路径，没有覆盖用户单独预览HTML的场景；相对路径要求素材目录也同时存在。现已移除这项封面路径依赖，保留原有构图、页面入口和43项占位。

补充验收：只复制这一份HTML到没有任何素材目录的新位置，从新的根路径打开并逐一检查首页、作品列表、详情与放大查看；核对内嵌数据与独立WebP的SHA256完全相同。相关结果记录到检查记录。正常交互与原图链接继续检查，不把整库路径通过当作单文件通过。

本文件可独立搬移，正式网站将来采用外置图片缓存或其他策略时另行处理；不将此审阅方案自动设为正式开发规范。
