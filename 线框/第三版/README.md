## 与第二版的区别

| 方面 | 第三版行为 | 边界 |
| --- | --- | --- |
| 页面与返回 | 首页／作品／关于／联系导航保持不变；原型内前进、后退和返回作品处理阅读位置与焦点 | 自包含原型中的历史处理，不是正式站点路由实现 |
| NED 章节与语言 | 章节跳转与历史返回；语言切换优先保留 URL 已选章节 | 无已选章节时不宣称能精确恢复所有阅读位置；完整译文待审阅 |
| 手机菜单 | 保持行内展开，增加 Escape 收起及焦点返回；点击菜单外收起 | 没有改成 Dennis 的整屏菜单 |
| 图片查看 | 打开后背景滚动锁定；Tab／Shift+Tab 留在查看层；关闭恢复阅读位置与触发图位焦点 | 仍是占位图片，原作品尚未接入 |
| 图组操作 | 保留 9 组 44 项；按钮、左右键、序号与首尾边界 | 不自动轮播、不跨组，无手势翻页 |
| 动效对照 | 轻量按钮反馈、菜单淡入、查看层淡入、桌面缩略图轻微缩放；关闭即时生效 | 数值为候选；无整页遮罩、磁吸、跟随光标或 Beedog 动画 |
| 减少动态效果 | 默认遵循系统偏好，也可手动关闭；偏好变化时更新 | 不把静态对照写成全站无障碍验收 |
| 状态演示 | 加载、失败、缺译可选，均有明显“模拟／演示”标记及退出方式 | 不发起真实图片加载，不伪造成功、重试、正式译文或联系服务 |

## 建议怎么审阅

1. **网站主路径：** 首页 → 关于，或首页 → 作品 → NED → 返回作品。使用浏览器前进／后退，观察阅读位置与焦点。
2. **长案例：** 从目录选择“我的工作”或其他章节，再切换英文，检查仍是否落在对应章节。当前英文仍为草稿。
3. **手机菜单：** 缩窄窗口后打开菜单，按 Escape 收起；使用 Tab／Enter／Space 操作，或点击正文区域收起。
4. **图片查看：** 打开 NED 任一图位，使用按钮或左右键切换；尝试 Tab／Shift+Tab，再按 Escape 关闭，检查回到原图位和阅读位置。
5. **动效比较：** 展开顶部“页面与预览设置”，选择“轻量动效 · 遵循系统偏好”与“关闭动效 · 静态对照”，完成同一操作。启用系统减少动态效果时，默认轻量模式也停用动画。
6. **模拟状态：** 选择图片加载或失败演示，再打开 NED 图位；“结束演示，恢复占位”只恢复原型占位，不代表真实网络加载成功。选择英文缺译演示后切换英文，可回同页中文或退出演示查看英文草稿。

顶部设置属于审阅工具，不是正式网站主导航。固定画布仍提供 1440px／390px 对照，自适应模式按实际窗口重排。

## 本轮候选参数

| 项目 | 原型值 | 实际处理 |
| --- | --- | --- |
| 按钮状态过渡 | 140ms | 灰度背景／边框反馈，焦点样式保留 |
| 菜单出现 | 200ms | 行内内容淡入；收起即时 |
| 查看层出现 | 160ms | 淡入；关闭即时，优先恢复操作与焦点 |
| 缩略图悬停 | 200ms、1.015 倍 | 仅精确指针的入口缩略图，正文图不缩放 |
| 系统减少动态／手动关闭 | 无动画与过渡 | 导航、菜单和图片操作照常可用 |

以上均是灰度样稿中的比较值，未成为品牌规范或用户确认的最终 UI 参数。未安装动画库或网站框架。

- 原有[清单](../../UI设计/交互与动效清单.md)的第二版基线保持历史记录；第三版落实范围单独补充，不把 M05–M09 后续候选写成已完成。
